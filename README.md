# ChatNUR

Стартовая версия веб-приложения ChatNUR.

## Что уже есть
- адаптивный интерфейс чата;
- PWA-манифест для установки на главный экран;
- Service Worker для базового кеширования;
- название и описание ChatNUR.

## Важно
Сейчас это **демонстрационный интерфейс**, а не подключённый ИИ. Чтобы ChatNUR отвечал с помощью модели, нужно развернуть отдельный сервер и подключить его к интерфейсу. Не размещайте API-ключи в `index.html` или публичном GitHub-репозитории.

## Публикация
Для простого статического размещения можно использовать GitHub Pages или другой HTTPS-хостинг. После публикации сайт можно добавить в Google Search Console. Индексация Google занимает время и не гарантируется мгновенно.

Для установки на iPhone откройте опубликованный сайт в Safari → Поделиться → На экран «Домой».
