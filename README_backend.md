# ChatNUR: подключение ИИ

`personality.txt` содержит характер ChatNUR. `server.py` — стартовый сервер, который отправляет сообщения в OpenAI Responses API.

Важно:
- Одной загрузки этих файлов на GitHub Pages недостаточно: backend нужно отдельно развернуть на сервере.
- API-ключ хранится только в приватной переменной окружения `OPENAI_API_KEY` на сервере. Никогда не помещайте его в HTML или публичный репозиторий.
- API оплачивается отдельно от подписки ChatGPT.
- Перед публичным запуском нужны HTTPS, ограничения запросов, защита от злоупотреблений, лимиты расходов и точная настройка CORS.
- Этот пример — основа для разработки, а не готовая коммерческая система с аккаунтами и подписками.

Для запуска на сервере: `pip install -r requirements.txt`, затем `uvicorn server:app --host 0.0.0.0 --port 8000`.
